Canine babesiosis scoping review

Machine-learning experiment plan

Candidate experiments over the data behind the 444 canine-evidence articles in the index: the individual-dog datasets, the pooled cohorts, the extracted severity evidence, and the article corpus itself. Each card says what question it answers, what data it uses, which method fits, what it produces, and where it can mislead.

Prepared 5 November 2026. Build specifications for each experiment are in experiment_specs/ (one Markdown file per code, conventions in its README). Experiment outputs follow the shape of data/experiments/EXP01-DS05-pairwise.json, which the console loader already writes to dbo.experiment, dbo.association, dbo.cluster_assignment and dbo.experiment_result.

Framing and constraints

The dataset catalogue in datasets.md states the limit plainly: no dataset combines a large independent cohort, a hard outcome, rich phenotypes and omics. Every verified dataset is small relative to its feature count. That shapes what machine learning can honestly do here.

What ML can do

Find structure in admission phenotypes, rank candidate markers by association with outcome, synthesise evidence across 275 extracted associations, and map the literature in ways the hand-built categories cannot.

What it cannot do

Produce a deployable prognostic model. Fifteen deaths in the one cohort with an outcome support one or two stable predictors, not a scorecard. Clusters are phenotype groupings, never disease subtypes.

What already exists

EXP01 tested 740 variable pairs in DS05 with permutation p values and Benjamini-Hochberg adjustment. Articles are embedded for semantic search. Severity associations are extracted and mapped to canonical markers.

Experiments are grouped into three layers by the unit of analysis:

Layer 1one dog per row, inside one dataset Layer 2dogs or findings pooled across cohorts and articles Layer 3one article per row, the corpus itself

Layer 1: single datasets one dog per row

Experiments that stay inside one tidy dataset. These are cheapest to run because the tidy format, the experiment JSON and the loader already exist.

EXP02

Admission phenotype structure in DS05

ClusteringBuilt and loaded, 5 Nov 2026
Question
Do the 150 BET dogs fall into recognisable admission phenotypes, and which laboratory axes drive the separation?
Data
DS05 tidy file: 28 numeric admission variables (haematology, biochemistry, vitals) and 11 categorical ones. Exclude the authors' derived classes from the inputs and keep them for comparison.
Method
Standardise, then PCA or factor analysis to find the main axes (expected: a regenerative-anaemia axis, an inflammatory left-shift axis, a protein axis). Cluster dogs with hierarchical linkage and a Gaussian mixture; choose k by silhouette and BIC; test stability by bootstrap resampling and consensus clustering. Project with UMAP for the figure only.
Output
Loadings per axis, cluster assignments per subject (into cluster_assignment), stability scores, and a cross-tabulation of clusters against anaemia class, left shift, habitus and PCR co-infection.
Reads with
EXP01 associations: a cluster that only recapitulates one strong pairwise correlation is not new information.
Result
Negative finding. Parallel analysis kept four axes (anaemia first, then inflammation). Ward clustering chose two groups of 91 and 57 dogs, but the silhouette of 0.16 did not beat a Gaussian null (p = 0.20): the cohort is a continuum, and the groups mostly restate the anaemia grade (Cramer's V 0.84, circular). Loaded as EXP02-DS05-clustering.
Caveat. Clusters must be reported as phenotype groupings, not subtypes. With no outcome in DS05, nothing here is prognostic.
EXP03

Mortality marker ranking in the Onderstepoort cohorts

PredictionNeeds tidy files
Question
Which admission markers carry the most information about death, and does the ranking hold over time within the cohort?
Data
S-CB050 (161 dogs, 15 deaths, myeloperoxidase index) with the S-CB517 cytokine columns merged in. The spec writer checked the files value by value: S-CB517's 112 dogs are S-CB050 cases 1 to 97 plus controls, with identical cytokine cells and the same 12 deaths, so there is one cohort, not two.
Method
Penalised logistic regression (L1 and elastic net) and a random forest, each inside nested cross-validation with stratified folds. Permutation importance, calibration curves, AUC with bootstrap intervals, and a permutation test of the whole pipeline to check that the AUC beats chance. Temporal transfer inside S-CB050: train on the 2011 to 2013 dogs, test on the 2014 dogs (only 3 deaths, so a reference check rather than validation).
Output
Ranked marker list with interval estimates, temporal-split AUC, and a comparison to the markers the two articles reported as prognostic.
Caveat. Fifteen events support one or two predictors in a stable model. The deliverable is a ranking, not a prognostic score. Report the event-per-variable ratio next to every result.
EXP04

Serum proteome classes in DS07

PredictionNeeds tidy file
Question
Which proteins separate complicated from uncomplicated B. rossi infection once the healthy-control contrast is removed?
Data
DS07 processed proteome, 52 samples in three classes (20 control, 18 uncomplicated, 14 complicated), 224 master proteins of which 112 pass the article's filter.
Method
Sparse PLS-DA and multinomial elastic net with repeated cross-validation; stability selection across resamples to keep only proteins chosen in most runs; permutation testing of class labels. A second pass restricted to the two infected classes.
Output
Stable protein panel per contrast, pathway grouping of the panel, and a comparison against the article's differential list.
Caveat. Features still outnumber samples. False-discovery control and stability matter more than model accuracy; a single cross-validated accuracy figure is meaningless here.
EXP05

Longitudinal structure in the beagle series, DS03 and S-CB017

Time seriesNeeds tidy files
Question
How do markers move together through the course of infection, and do complicated dogs follow a different trajectory from uncomplicated ones?
Data
DS01, DS02 and DS06: six experimentally infected beagles with daily haematology, cytokines and whole-blood transcriptome by dose group. DS03: reticulocyte kinetics in 139 dogs. S-CB017: three chemokines in 47 dogs with a complicated versus uncomplicated label.
Method
Linear mixed-effects models with dog as random effect and dose by day fixed effects. Time-series clustering of standardised marker trajectories. For the transcriptome, co-expression module detection in the style of WGCNA and module eigengene trends over days. For S-CB017, latent-class trajectory models and a check of whether class membership tracks the complication label.
Output
Trajectory clusters, module membership tables, and effect estimates per marker over time.
Caveat. Six animals rule out any prediction, and DS01, DS02, DS06 and the experimental arm of DS03 all describe the same five infected beagles. Treat the beagle results as descriptive kinetics that generate hypotheses for the natural-infection cohorts.
EXP06

Atypical dogs in DS05

Anomaly detectionBuilt and loaded, 5 Nov 2026
Question
Which dogs have admission profiles that do not fit the rest of the cohort, and do the three E. canis co-infected dogs stand out?
Data
DS05 numeric admission variables.
Method
Isolation forest and robust Mahalanobis distance; compare the two outlier scores; list the top-scoring dogs with the variables that drive the score.
Output
Per-subject anomaly score as an experiment result, and a short table of outliers for clinical review.
Result
148 dogs scored over 22 variables; 8 labelled atypical (top 5 percent of the combined rank score). The two methods agree (Spearman 0.82, 5 of the top 10 shared). The top dogs are driven by real recorded extremes: monocytosis with hyperproteinaemia, hypothermia of 33 to 34 C, a haematocrit of 0.63, a haemoglobin of 18 g/L. All 15 listed dogs were checked against the raw sheet: 14 match; BET048's red cell count equals its white cell count and is treated as an entry slip. None of the three co-infected dogs or the B. vogeli dog is among the top 10. Loaded as EXP06-DS05-anomaly.
Caveat. Outliers are as likely to be data-entry or unit errors as biology. Check each one against the raw sheet before interpreting it.

Layer 2: across cohorts and the evidence table pooled

Experiments that combine datasets, or that treat the extracted findings from many articles as the data.

EXP07

Harmonised pooled haematology

Mixed modelsNeeds harmonisation
Question
Do the main haematological relationships hold across cohorts, and does a severity signal learned in one cohort transfer to another?
Data
Haematocrit, platelets, white cell count, band neutrophils and albumin appear in DS05, S-CB050, S-CB517, S-CB017, DS03 and S-CB013. Units and reference ranges differ by laboratory.
Method
Harmonise units and record every conversion as a variable note. Fit mixed models with cohort as a random effect for the pairwise relationships EXP01 found in DS05. For cohorts with an outcome, train a minimal severity score in one and test it in the other; report transfer loss.
Output
A pooled tidy dataset with provenance per column, cohort-adjusted effect sizes, and the transfer results.
Caveat. Cohorts differ by species (B. rossi versus B. canis), country and hospital. Species must enter the model, and the source-group letters identify animals that appear in more than one dataset.
EXP08

Severity evidence matrix and meta-analysis

Evidence synthesisReady to run
Question
Which markers are consistently associated with severity or death across articles and species, which disagree, and which were only ever tested once?
Data
The 290 rows of associations.csv: marker, outcome class, direction, significance, effect type and value, species, n, and the extraction confidence. marker_map.csv for canonical names and classes.
Method
Build a marker by outcome-class matrix of direction and significance. Where effect types are comparable (odds ratios, standardised mean differences, AUCs), run random-effects meta-analysis per marker with heterogeneity statistics. Elsewhere, a vote-counting heatmap weighted by sample size. Cluster markers on their association profile to see which behave alike. Split everything by species.
Output
Heatmap figure, forest plots for markers with three or more comparable estimates, and a list of single-study markers as explicit evidence gaps.
Caveat. Extraction rows carry a confidence field and a quote check. Use only high-confidence rows for the pooled estimates and show the rest separately. Articles sharing a cohort identifier are one study, not several.
EXP09

Co-infection association rules

Association rulesNeeds tidy files
Question
Do particular pathogen combinations occur more or less often together than chance predicts, and do they carry a distinct admission picture?
Data
DS05 PCR panel (B. rossi, B. vogeli, E. canis, T. equi) and the S-CB013 community screen (96 dogs; B. vogeli, A. platys and two haemotropic mycoplasma targets, no Ehrlichia). Any other dataset that reports more than one pathogen.
Method
Apriori or FP-growth over pathogen presence with lift and confidence; Fisher exact tests on each pair; for DS05, compare haematology between co-infected and single-infected dogs with the same permutation tests used in EXP01.
Output
Rule table with support, confidence and lift; a short comparison table for co-infected dogs.
Caveat. DS05 has three co-infected dogs. The rule mining is informative in S-CB013; in DS05 it is a description, not a test.

Layer 3: the article corpus one article per row

Experiments where the literature itself is the data. These improve the review and its categorisation rather than the clinical findings, and they reuse the embeddings and term extraction already in the database.

EXP10

Topic map versus the automatic classifier

Topic modellingReady to run
Question
Does a data-driven topic structure agree with the hand-defined categories, and where it disagrees, which articles deserve a human look?
Data
Article embeddings in SQL Server (453 articles loaded), abstracts and full text where available (230 of 481 are abstract-only), and the automatic primary category and secondary tags.
Method
Cluster the embeddings (HDBSCAN over a UMAP reduction, as in BERTopic) and label clusters by class-based TF-IDF terms. Cross-tabulate topics against categories; measure agreement with adjusted mutual information. Articles whose topic and category disagree, or that sit between clusters, go to a review queue. Repeat the clustering per decade to see topic drift.
Output
Interactive literature map, topic by category table, review queue, and a per-decade topic trend.
Caveat. The classifier assigned categories with no human review. Treat disagreements as flags for inspection, not as errors in either direction.
EXP11

Supervised classifiers for article metadata

ClassificationReady to run
Question
How reliable are the automatic category, evidence type and study design labels, and can a trained model do better?
Data
Article text, embeddings and the current labels; the category confidence field as a weak signal of label quality.
Method
Logistic regression and gradient boosting on embeddings and TF-IDF features, cross-validated. Hand-label a stratified sample of around 60 articles as a gold set; report agreement for the existing labels and the new model. Use uncertainty sampling to choose the next articles to label.
Output
Measured error rates per label, a model with calibrated probabilities, and an active-learning queue.
Caveat. Training on the automatic labels learns their mistakes. The gold set is the point of the experiment; without it the result is circular.
EXP12

Research-gap grid and trends

DescriptiveReady to run
Question
Which combinations of species, category, evidence type, country and period have no or almost no articles, and which topics are growing or fading?
Data
Article metadata fields and cohort identifiers.
Method
Contingency grids with expected counts under independence; cells with large negative residuals are the gaps. Poisson or negative-binomial trend models per category over publication year. Count cohorts, not articles, where cohort identifiers exist.
Output
Gap heatmaps and a trend chart, written as an experiment result so the web app can show them.
Caveat. Absence in this index means absence in the search strategy, not necessarily in the literature. State the search log alongside any gap claim.
EXP13

Marker knowledge graph and link prediction

GraphLarger effort
Question
Across the whole corpus, which markers, outcomes and species are connected, and which plausible marker-to-outcome pairs have never been tested?
Data
The severity extraction is a 10-article pilot. Extend the same extraction prompt and schema to all 444 canine articles, then build a graph of marker, outcome, species, specimen and article nodes.
Method
Named-entity and relation extraction with the existing schema and quote checks. Graph measures (degree, betweenness) to find hub markers. Link prediction by node embeddings or simple common-neighbour scores to rank untested pairs. Validate against pairs tested in recent articles held out of the graph.
Output
Graph export, hub table, ranked list of untested marker-outcome pairs with the evidence that makes each plausible.
Caveat. Extraction errors propagate into the graph. Keep the quote-check field and exclude rows that fail it.
EXP14

Hidden cohort overlap

SimilarityReady to run
Question
Which articles reuse the same animals without sharing a cohort identifier?
Data
Methods sections from the full-text store, author lists, institutions, study dates and sample sizes; the 38 known cohort identifiers as positives.
Method
Embed methods sections and compute pairwise similarity; combine with author overlap and matching recruitment dates in a simple pair classifier trained on the known cohort pairs. Review the top-scoring unlinked pairs.
Output
Candidate cohort links for confirmation, and corrected independent-cohort counts for the research map.
Caveat. Same authors and same hospital do not prove the same dogs. Each candidate link needs a human decision before the research map changes.
EXP15

What predicts shared data

Meta-scienceReady to run
Question
Which kinds of study share individual-level data, and has that changed over time?
Data
Dataset status code per article, publication year, journal, country, evidence type, species, open-access status.
Method
Logistic regression and a shallow tree on the status code with year as a trend term. Report odds ratios with intervals.
Output
A short table of predictors for the data-availability section of the review.
Caveat. Status 5 articles were not assessable because full text was inaccessible. Model availability only among assessed articles, or model accessibility separately.

Guardrails for every experiment

These belong in each experiment's parameters block so the loader and the web app can display them next to the results.

  • Permutation p values and Benjamini-Hochberg adjustment across the whole run, as EXP01 does, so that no single comparison is read outside its family.
  • Nested cross-validation for anything predictive, with feature selection inside the inner loop. A single train-test split on a cohort of 150 is not evidence.
  • Effect sizes with intervals alongside every p value: Cramer's V, eta squared, Spearman rho, odds ratios, AUC with bootstrap bounds.
  • Non-independence declared. Source-group letters for datasets and cohort identifiers for articles decide what counts as replication.
  • Species as a variable, never pooled silently. B. rossi, B. canis, B. gibsoni and B. vogeli differ in severity and in the markers studied.
  • Labels are weak. Complicated versus uncomplicated is defined differently by different authors; record the definition with the label.
  • Missingness analysed before imputation, with a sensitivity analysis under complete cases and under multiple imputation.
  • Clusters are groupings, not subtypes. Stability and clinical interpretability are reported with every clustering.
  • Reproducibility fields in each output: script path, script version hash, seed, run time, dataset code and parameter block, as in EXP01.

Suggested order

Ordered by how much existing infrastructure each experiment reuses and how much it would change the review's conclusions.

  1. EXP02 and EXP06 on DS05.

    The tidy file, loader and result tables exist. Clustering and anomaly scores extend EXP01 directly and exercise the cluster_assignment path in the web app.

  2. EXP03 mortality marker ranking.

    The only hard outcome in the collection. Needs tidy files for S-CB050 and S-CB517 first, following the DS05 tidy script as the template; the two files describe the same dogs and are merged.

  3. EXP08 severity evidence matrix.

    Uses tables that already exist and speaks directly to the review's central question. No new extraction needed for a first version.

  4. EXP07 pooled haematology.

    Builds on the tidy files produced for EXP03 and gives the first cross-cohort check of the DS05 findings.

  5. EXP10, EXP11 and EXP12 as a corpus stream.

    Independent of the clinical experiments and can run in parallel. They improve the categories and the research map that the web app already shows.

  6. EXP04, EXP05, EXP09, EXP14 and EXP15.

    Each needs one more tidy file or a modest extension of existing scripts. Schedule as the earlier results suggest.

  7. EXP13 knowledge graph.

    The largest effort and the one most dependent on extraction quality. Start once the severity extraction has been validated by EXP08.
