# Search log and methods

[Back to article index](index.md)

## Review window and run

- **Window:** 2006-10-23 to 2026-10-23 inclusive, searched in rounds: r1-r3 2016-10-23 to 2026-10-23 (searches run 2026-10-23; complete); r4 2006-10-23 to 2016-10-22 (searches run 2026-10-27; complete). Applied to the **first publication date** = the earlier of the electronic (online) and issue dates in the PubMed record; Europe PMC `FIRST_PDATE`; Crossref earliest of published-online/print/issued; OpenAlex `publication_date`. Online-vs-issue discrepancies are recorded per article (`date_note` in [articles.jsonl](articles.jsonl)).
- **Scripts:** all in `scripts/` (Python 3.13 standard library only; run with `python -I` from `canine-babesiosis-review/`). Raw query outputs are kept in `search/` (rounds 1-3) and `search/<round>/` (later rounds); the rounds are listed in `search/rounds.json`.
- **Status: rapid scoping review, not an exhaustive systematic review.** Single-pass, LLM-assisted screening and extraction with a second-screener check (see below); no duplicate independent human screening; no formal risk-of-bias assessment.

## Reproduction

```bash
python -I scripts/search.py --start 2016-10-23 --end 2026-10-23        # PubMed + Europe PMC (+ OpenAlex relevance search, failed keyless)
python -I scripts/citations.py --start 2016-10-23 --end 2026-10-23     # backward/forward citation search (Europe PMC)
python -I scripts/crossref_search.py --start 2016-10-23 --end 2026-10-23
python -I scripts/openalex_search.py --start 2016-10-23 --end 2026-10-23
python -I scripts/search.py --start 2006-10-23 --end 2016-10-22 --round r4
python -I scripts/citations.py --start 2006-10-23 --end 2016-10-22 --round r4 --registry-seeds
python -I scripts/crossref_search.py --start 2006-10-23 --end 2016-10-22 --round r4
python -I scripts/openalex_search.py --start 2006-10-23 --end 2016-10-22 --round r4
python -I scripts/merge_candidates.py --round r4                        # -> search/r4/candidates_all.jsonl
python -I scripts/repo_search.py                                       # dataset repositories
python -I scripts/fulltext_checks.py search/included_keys_r1.txt        # Europe PMC OA full text: data statements, supplements
python -I scripts/assign_ids.py                                        # stable IDs (ids.json) + extraction packets
python -I scripts/fetch_datasets.py data/fetch_spec_repos.json         # downloads with caps + SHA-256 manifest
python -I scripts/fetch_datasets.py data/fetch_spec_supp.json
python -I scripts/inspect_files.py DS01 ...                            # structure summaries -> data/inspection/
python -I scripts/table_dump.py "<file>[::zip member]" --sheet N        # read-only table viewer
python -I scripts/build_datasets.py && python -I scripts/render_datasets.py
python -I scripts/build_outputs.py && python -I scripts/build_search_log.py
python -I scripts/validate.py
```
Re-running the round 1-3 searches overwrites `search/*.jsonl` and will return newer records. A later round (`--round`) writes to its own `search/<round>/` folder and leaves out records already collected or screened in earlier rounds; records that already have an article ID (for example background papers inside the new window) are kept and flagged with `existing_id`. `ids.json` is append-only, so existing IDs never change (excluded records keep their retired IDs).

### Eligibility decisions worth noting

- Clinicopathological profiles of infected dogs (haematology/biochemistry case series) were **included** as descriptive evidence, because they characterise syndromes; they are labelled `descriptive`.
- Prevalence/molecular surveys, vector studies, diagnostic-assay development and treatment-efficacy trials were excluded unless they reported host pathophysiological data.
- Wild *Canis lupus* (grey/Iberian wolf) studies were kept as canine evidence; red fox and other non-*Canis* canid studies were excluded unless dog data were present (CB150, red fox, excluded).
- Case reports were included only when they described a distinct syndrome or mechanistic observation (e.g. Evans syndrome, vasculitis, haemophagocytic syndrome, ARDS, cerebral involvement).
- Many round-3 inclusions are from regional journals not indexed in MEDLINE; some show signs of limited peer review. They were retained (not excluded on venue) but flagged in notes; most are small descriptive series.
- Seed review (BG001) kept as background; it is a prevalence meta-analysis and is not counted as eligible canine evidence.

## Verification

- Records with a PMID were taken from the PubMed XML record (title, authors, journal, dates, DOI, PMCID, publication types, CommentsCorrections for errata/retractions). Records without a PMID were verified against Crossref, the DOI landing page or the publisher page by extraction agents; when no authoritative record could be confirmed the record was marked unresolved.
- Summaries were written from the actual abstract (PubMed, publisher page or Crossref); OpenAlex abstracts are reconstructions of inverted indexes and were confirmed against the publisher page where reachable. A second agent (Claude Haiku) cross-checked every canine note against its source abstract (numbers, design, identifiers, ≤8-word verbatim runs, causal language) and edited where needed.
- Corrections/retractions: PubMed CommentsCorrections were checked for all PubMed records; 0 included records carry a correction note (see `corrections` in articles.jsonl). Non-PubMed records: checked in Crossref `update-to`/`relation` where accessible, otherwise 'not checked'.

## Coverage limitations

- **Not exhaustive.** CAB Abstracts, Web of Science, Scopus and Google Scholar were not searched; regional veterinary literature (India, Ukraine, Russia, Türkiye, Brazil, Eastern Europe) is reached only through Crossref (relevance-capped) and OpenAlex, so further non-indexed papers almost certainly exist.
- **Language:** no language restriction was applied to searching, but screening used English titles/abstracts; non-English records with English abstracts were included (Portuguese, Ukrainian, Russian, German, Romanian, Turkish, French, Serbian). Records whose abstract or full text was only in a language/platform we could not access (e.g. eLIBRARY.ru, CroRIS bot checks) are listed as unresolved. Effect: likely under-representation of Russian- and Chinese-language clinicopathology.
- **Access:** full text was checked programmatically for PMC open-access articles and via publisher pages for others (179 of 444 included canine articles); 191 could not be read beyond the abstract (dataset status 5).
- **Theses/dissertations** (153 in the round-3 OpenAlex set and 124 in round 4, including University of Pretoria and Indian veterinary theses) and conference abstracts were excluded as not peer-reviewed, although some underlie included papers and datasets (e.g. DS03–DS05 cite UP dissertations).
- **LLM-assisted screening/extraction:** decisions were made by language-model agents following written criteria with a second-screener rescue pass, not by duplicate human reviewers. Misclassification is possible, especially for borderline descriptive papers and for poorly reported regional articles.
- **Cohort linkage** is inferred from reported institutions, periods and n; 3 of 38 cohort groupings are explicitly confirmed by the authors, the rest are probable (see [research map](research-map.md#cohorts)). Further unrecognised overlap is likely, especially among Onderstepoort, Zagreb and Ukrainian groups.
- **Search end-date effects:** records first published close to 2026-10-23 may not yet be indexed.
