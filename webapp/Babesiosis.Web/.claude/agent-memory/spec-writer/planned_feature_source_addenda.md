When a caller relays user decisions for a planned feature (e.g. Data Health rebuild 2026-09-29), write them first as a
"User direction <date>" block in `working/answers/<module>.md` under the document's section, and append each mid-run
decision from the coordinator as "Addendum N". Writers cite that block; answered items become closed IDs.

**Why:** planned-document rule allows only overview / working draft / answers file as sources; the coordinator sent
three extra decision batches mid-run (new shared grid, control panel, four answers) and every revise needed a stable source.
**How to apply:** reserve question blocks and write the source block before launching writers; for later batches add an
addendum, then launch revise runs in parallel with prescribed section numbers so siblings can cross-link. Grep glossary
rows across sibling docs at integration — parallel writers define shared terms twice. See [[subagent-return-checks]].
