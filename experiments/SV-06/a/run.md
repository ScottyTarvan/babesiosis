# SV-06a run

From `/experiments/SV-06/a/` in Git Bash, after `environment.md`.

The family files `families/F1.json` … `families/F7.json` are the literature step: seven Claude sub-agents (one per family) wrote them from `families/BRIEF.md` and `spec.md` on 2026-11-12, using PubMed and the review corpus. They are inputs to the scripted part, not regenerated by it. To redo the literature step, give a new sub-agent `families/BRIEF.md` and its family number.

Scripted part (deterministic, no random numbers):

```bash
env/py/Scripts/python.exe -I scripts/local_search.py      # out/local_hits.json, out/reference_lookup.json (seeds + agent-added mechanisms)
env/py/Scripts/python.exe -I scripts/assemble.py          # out/transfer_grid.csv, ranked_gaps.csv, family_summary.csv, candidates_for_partb.json, out/db/SV-06-01-transfer-grid.json
env/py/Scripts/python.exe -I scripts/write_db.py --dry-run
env/py/Scripts/python.exe -I scripts/write_db.py          # dbo.experiment + dbo.experiment_result for SV-06-01-transfer-grid, one transaction
```

Check query:

```sql
SELECT e.experiment_code, e.method, e.run_at, COUNT(r.result_id) AS results,
       SUM(CASE WHEN r.result_kind = 'interpretation' THEN 1 ELSE 0 END) AS interpretation
FROM dbo.experiment AS e LEFT JOIN dbo.experiment_result AS r ON r.experiment_id = e.experiment_id
WHERE e.experiment_code = 'SV-06-01-transfer-grid'
GROUP BY e.experiment_code, e.method, e.run_at;
```

Rerun check: delete `out/` and run the first two commands again; every file except the `run_utc` field of the load file must be byte-identical.
